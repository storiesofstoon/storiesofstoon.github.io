# Stories of Stoon — GitHub Pages site

This package follows the supplied `site.zip` theme, including its city backdrop, graffiti logo, colors, and original character-bio page.

## Deploy
1. Extract this ZIP.
2. Upload the **contents** directly into the publishing root of the GitHub repository for `storiesofstoon.github.io` (not the outer folder).
3. Commit changes; GitHub Pages will serve `index.html`.

Main URLs: `index.html` (launch), `preview.html` (17-page free PDF), `bios.html` (existing bios), `reader.html` (redirects to preview), `archive.html` (launch landing until the archive is restored).

The preview PDF is `assets/free-preview.pdf`. The Amazon and buy-direct sections are informational placeholders, with no invented purchase links or release date. Existing MailerLite form ID WV0NZp and integration script have been retained from the reference site; verify the form appears on the live domain.

To publish sales links later, change `index.html` inside the `coming-options` section.
